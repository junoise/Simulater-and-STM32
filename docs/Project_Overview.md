## ●프로젝트 목표

항공 시뮬레이터를 구현하고, 시뮬레이터로부터 항공기 상태 정보를 수신하는 STM32 + FreeRTOS 기반 임무 컴퓨터 시스템을 개발한다. 임무 컴퓨터는 수신한 정보를 실시간으로 처리하여 현재 임무 상태를 판단하고, 판단 결과에 따른 명령을 항공 시뮬레이터로 전송한다.

## ●입력/처리/출력

### 입력(시뮬레이터 -> STM32)
Roll/Pitch/Yaw,고도,위치(위도,경도),연료,풍속,바람의방향,기체속도

### 처리(STM32)
데이터 유효성 검사, 현재 비행 상태 판단, 현재 임무 단계 판단, 목표 지점 관리, 연료 상태 판단, 환경 상태 판단, Guidance 계산, 목표 상태 생성, 비상 상황 판단, 필요시 RTB 결정

### 출력(STM32->시뮬레이터)
목표 방위각, 목표 고도, 목표 속도, 현재/다음 목표 지점, 임무 상태, 기지 복귀 명령, 비상 명령, 임무 중단/완료 명령
<br><br><br>
## ●임무 시나리오 정의(상태)

대기-> 이륙-> 상승-> 순항-> Waypoint1/2 ->목적지 접근-> 하강->접근->착륙->종료
대기(Standby): 임무 시작 명령 대기 
대기(Standby): 비행 시작 명령 대기 
이륙(Takeoff): 활주 및 이륙 수행 단계 
상승(Climb): 지정된 순항 고도까지 상승 
순항(Cruise): 목표 고도와 속도를 유지하며 비행 계획에 따른 Waypoint로 이동 
Waypoint 1 / 2: 각 Waypoint 도달 여부를 판단하고 다음 Waypoint로 전환 
목적지 접근(Destination Approach): 목적지 공항 접근을 위한 경로 및 상태 전환 
하강(Descent): 목적지 접근을 위해 지정 고도까지 단계적으로 하강 
접근(Approach): 착륙을 위해 활주로 방향·고도·속도를 맞추는 단계 
착륙(Landing): 최종 착륙 수행 단계 
종료(Flight Complete): 착륙 완료 후 비행 종료 상태
