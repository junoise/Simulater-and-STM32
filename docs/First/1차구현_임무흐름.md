# 1차 구현의 임무 흐름 정의 
<br>
상태는 INITIALIZE -> NAVIGATE -> MISSION_COMPLETE 3가지로 나눈다.
<br>

## 상태 정의

### INITIALIZE
임무를 시작하기 전 통신 여부와 초기 데이터를 확인하는 단계

수행해야 할 것:
#### Stm32
  - Unity와 통신이 연결 되었는가?
  - 수신한 항공기 상태의 데이터가 정상인가?
  - 목표지점을 기반으로 Waypoint 목록 생성
  - 생성한 첫번째 Waypoint를 현재 목표 지점으로 설정
  -  Waypoint 목록을 unity에 전송
  - 모든 과정이 완료되면 navtigate로 상태를 변경한다. 
#### Simulater
  - Stm32와 통신이 연결 되었는가?
  - 임의의 목표지점 생성 및 송신
  - 항공기의 상태 데이터 송신
  - Waypoint 수신이 되었는가?
  - 수신한 Waypoint목록을 UI에 표시한다.

### NAVIGATE
목표지점에 도달하기 전까지 반복작업을 하는 단계(자동비행)

수행해야 할 것:
#### Stm32
  목표도달까지 반복(
  1. Unity로부터 데이터 수신
  2. 데이터 유효성 검사 
  3. 현재 위치와 WayPoint 간 거리 계산
  4. Waypoint 도달 여부 판단)

  Waypoint 도달 하지 않았을 경우
  1. 목표 Heading 계산
  2. 목표 Altitude와 Speed 계산
  3. 목표 값을 Unity에 전송
  4. 다시 1번으로
  Waypoint 도달 한 경우
  → 마지막 Waypoint인지 확인
  → 마지막이면 MISSION_COMPLETE
  → 마지막이 아니면 다음 Waypoint로 전환

  데이터가 유효하지 않은 경우
  - 수신한 데이터가 유효하지 않으면 새로운 Gudiance를 생성하지 않는다.
  - 데이터에 문제가 있다고 unity에 전송한다.
  - 다시 1번으로 돌아간다.
#### Simulater
  1. 기체의 데이터 전송
  2. STM32로부터 목표 Heading, Altitude, Speed 및 임무 상태를 수신
  3. 수신한 목표값을 자동조종 로직에 반영
  4. 변경된 목표값과 현재 상태를 UI에 반영

### Mission Complete
모든 WayPoint에 도달하여 1차 임무가 완료된 상태

#### Stm32
  1. 임무 상태를 Mission Complete로 변경한다.
  2. 새로운 Waypoint Gudiance생성을 중지
  3. 마지막 목표 Heading, Altitude,Speed를 유지
  4. 임무 완료 상태를 unity에 전송

#### simulater
  1. Stm32로 부터 임무 완료 상태를 수신한다.
  2. 마지막으로 수신받은 목표를 유지
  3. UI에 임무완료를 표시
