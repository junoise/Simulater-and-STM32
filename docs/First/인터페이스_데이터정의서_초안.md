본 문서는 Unity 와 STM32 간의 상호작용하는 인터페이스의 데이터에 대해서 정의하는 문서이다.

## Unity -> STM32
U2S -> Unity to STM32

| ID | 데이터명 | 자료형 | 단위 | 유효 범위 | 전송 시점 | 설명 |
|---|---|---|---|---|---|---|
| U2S-001 | current_latitude | float | degree | -90.0 ~ 90.0 | 주기적 | 기체의 현재 위도 |
| U2S-002 | current_longitude | float | degree | -180.0 ~ 180.0 | 주기적 | 기체의 현재 경도 |
| U2S-003 | current_altitude | float | m | TBD | 주기적 | 기체의 현재 고도 |
| U2S-004 | current_heading | float | degree | 0.0 이상 360.0 미만 | 주기적 | 기체의 현재 진행방향 |
| U2S-005 | current_speed | float | km/h | TBD | 주기적 | 기체의 현재 속도 |
| U2S-006 | current_fuel | float | % | 0.0 ~ 100.0 | 주기적 | 기체의 현재 연료량 |

| U2S-007 | destination_latitude | float | degree | -90.0 ~ 90.0 | INITIALIZE 시 1회 | 최종 목적지 위도 |
| U2S-008 | destination_longitude | float | degree | -180.0 ~ 180.0 | INITIALIZE 시 1회 | 최종 목적지 경도 |
| U2S-009 | destination_altitude | float | m | TBD | INITIALIZE 시 1회 | 최종 목적지 목표 고도 |
| U2S-010 | mission_start_command | uint8 | - | 0 또는 1 | 임무 시작 시 | 임무 시작 명령 |

## STM32 -> Unity
S2U -> STM32 to Unity
| ID | 데이터명 | 자료형 | 단위 | 유효 범위 | 전송 시점 | 설명 |
|---|---|---|---|---|---|---|
| S2U-001 | target_altitude | float | m | TBD | 주기적 | 목표 고도|
| S2U-002 | target_heading | float | degree | 0.0 이상 360.0 미만 | 주기적 | 목표 진행방향 |
| S2U-003 | target_speed | float | km/h | TBD | 주기적 | 목표 속도 |
| S2U-005 | current_waypoint_index | uint8 | - | 0 ~ TBD-1 | 주기적 | 현재 waypoint 순번 |
| S2U-006 | mission_state | uint8 | - | 0 , 1 , 2 | 주기적 | 임무 단계 |
| S2U-007 | data_status | uint8 | - | 0 , 1 , 2 | 주기적 | 마지막으로 수신한 항공기 데이터의 유효성 |

| S2U-004 | waypoint_list| list | - | 별도 명시 | 초기, 변경 시 | 목표 waypoint list | 

### waypoint list 세부 
| ID | 데이터명 | 자료형 | 단위 | 유효 범위 | 전송 시점 | 설명 |
|---|---|---|---|---|---|---|
| S2U-009 | waypoint_latitude | float | degree | -90.0 ~ 90.0 | 초기, 변경 시 | 목표 waypoint 위도 |
| S2U-010 | waypoint_longitude | float | degree | -180.0 ~ 180.0 | 초기, 변경 시 | 목표 waypoint 경도 |
| S2U-011 | waypoint_altitude | float | m | TBD | 초기, 변경 시 | 목표 waypoint 고도 |

### Mission State

| 값 | 상태 |
|---:|---|
| 0 | INITIALIZE |
| 1 | NAVIGATE |
| 2 | MISSION_COMPLETE |

### Data Status

| 값 | 상태 | 설명 |
|---:|---|---|
| 0 | UNKNOWN | 항공기 데이터를 아직 수신하지 않음 |
| 1 | VALID | 마지막으로 수신한 데이터가 유효함 |
| 2 | INVALID | 마지막으로 수신한 데이터가 유효하지 않음 |



### 통신 규칙

[             헤더              ] [ 실제 데이터 ] [ 오류 검출값 ]
[ 시작 표시 | 메시지 종류 | 길이 ]


| 구성 | 역할 |
|---:|---|
| 시작표시 | 패킷 시작 위치를 찾음 |
| 메시지 종류 | 메세지의 종류 |
| 데이터 길이 | 뒤에 데이터가 몇바이트 있는지 |
| 데이터 | 실제 전달 데이터 |
| 오류 검출 | 전송 내용이 손상됐는지 확인 |


#### 시작표시

- [0xAA][0x55] 로 설정

##### 메시지 종류

| 값 | 의미 |
|---:|---|
| 0x01 | U->STM 목적지 |
| 0x02 | U->STM 주기적 |
| 0x03 | STM->U waypoint |
| 0x04 | STM->U 주기적 |

#### 길이
- 1바이트: 데이터 길이 최대 255바이트. 
- 2바이트: 최대 65,535바이트. waypoint 개수가 늘어나도 여유

후를 위해 넉넉하게 2바이트,리틀엔디언으로 적용


#### 오류 검출
CRC-16/IBM-3740

[AA 55] [메시지 종류] [데이터 길이] [데이터] [CRC]
           └──────── CRC 계산 대상 ────────┘

#### 패킷구조
[AA 55: 2바이트] [종류: 1바이트] [길이: 2바이트] [데이터: 가변] [CRC: 2바이트]


#### 0x01
| 순서 | 데이터 | 전송 형식 | 크기 |
|---|---|---|---:|
| 1 | destination_latitude | IEEE 754 float32, 리틀 엔디언 | 4바이트 |
| 2 | destination_longitude | IEEE 754 float32, 리틀 엔디언 | 4바이트 |
| 3 | destination_altitude | IEEE 754 float32, 리틀 엔디언 | 4바이트 |
| 4 | mission_start_command | uint8, 0 또는 1 | 1바이트 |

- 데이터는 13바이트, 전체 패킷은 20바이트

#### 0x02
| 순서 | 데이터 | 전송 형식 | 크기 |
|---|---|---:|
| 1 | current_latitude | IEEE 754 float32, 리틀 엔디언 | 4바이트 |
| 2 | current_longitude | IEEE 754 float32, 리틀 엔디언 | 4바이트 |
| 3 | current_altitude | IEEE 754 float32, 리틀 엔디언 | 4바이트 |
| 4 | current_heading | IEEE 754 float32, 리틀 엔디언 | 4바이트 |
| 5 | current_speed — m/s | IEEE 754 float32, 리틀 엔디언 | 4바이트 |
| 6 | current_fuel | IEEE 754 float32, 리틀 엔디언 | 4바이트 |

- 데이터는 24바이트, 전체 패킷은 31바이트

#### 0x03
| 순서 | 데이터 | 형식 | 크기 |
|---|---|---|---:|
| 1 | waypoint_count | uint8 | 1바이트 |
| 2 | 1 waypoint 위도·경도·고도 | IEEE 754 float32 × 3 , 리틀 엔디언 | 12바이트 |
| 3 | 2 waypoint 위도·경도·고도 | IEEE 754 float32 × 3, 리틀 엔디언 | 12바이트 |
| 4 | 3 waypoint 위도·경도·고도 | IEEE 754 float32 × 3, 리틀 엔디언 | 12바이트 |
| 5 | 4 waypoint 위도·경도·고도 | IEEE 754 float32 × 3, 리틀 엔디언 | 12바이트 |
| 6 | 5 waypoint 위도·경도·고도 | IEEE 754 float32 × 3, 리틀 엔디언 | 12바이트 |

- 각 waypoint 내부 순서는 위도 → 경도 → 고도.
- 표의 첫 번째 waypoint는 코드의 인덱스 0, 다섯 번째는 인덱스 4.
- Payload 61바이트, 전체 패킷 68바이트.

[AA 55] [03] [3D 00] [05] [WP0] [WP1] [WP2] [WP3] [WP4] [CRC 2바이트]

#### 0x04

| 순서 | 데이터 | 형식 | 크기 |
|---|---|---|---:|
| 1 | target_altitude — m | IEEE 754 float32, 리틀 엔디언 | 4바이트 |
| 2 | target_heading — degree | IEEE 754 float32, 리틀 엔디언 | 4바이트 |
| 3 | target_speed — m/s | IEEE 754 float32, 리틀 엔디언 | 4바이트 |
| 4 | current_waypoint_index | uint8, 0~4 | 1바이트 |
| 5 | mission_state | uint8, 0~2 | 1바이트 |
| 6 | data_status | uint8, 0~2 | 1바이트 |

- Payload는 15바이트, 전체 패킷은 22바이트

[AA 55] [04] [0F 00] [고도][방향][속도][인덱스][임무 상태][데이터 상태] [CRC]
