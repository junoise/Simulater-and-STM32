본 문서는 Unity 와 STM32 간의 상호작용하는 인터페이스의 데이터에 대해서 정의하는 문서이다.

## Unity -> STM32
U2S -> Unity to STM32

| ID | 데이터명 | 자료형 | 단위 | 유효 범위 | 전송 시점 | 설명 |
|---|---|---|---|---|---|---|
| U2S-001 | current_latitude | float | degree | -90.0 ~ 90.0 | 주기적 | 기체의 현재 위도 |
| U2S-002 | current_longitude | float | degree | -180.0 ~ 180.0 | 주기적 | 기체의 현재 경도 |
| U2S-003 | current_altitude | float | m | TBD | 주기적 | 기체의 현재 고도 |
| U2S-004 | current_heading | float | degree | 0.0 이상 360.0 미만 | 주기적 | 기체의 현재 진행방향 |
| U2S-005 | current_speed | float | m/s | TBD | 주기적 | 기체의 현재 속도 |
| U2S-006 | current_fuel | float | % | 0.0 ~ 100.0 | 주기적 | 기체의 현재 연료량 |
| U2S-007 | destination_latitude | float | degree | -90.0 ~ 90.0 | INITIALIZE 시 1회 | 최종 목적지 위도 |
| U2S-008 | destination_longitude | float | degree | -180.0 ~ 180.0 | INITIALIZE 시 1회 | 최종 목적지 경도 |
| U2S-009 | destination_altitude | float | m | TBD | INITIALIZE 시 1회 | 최종 목적지 목표 고도 |
| U2S-010 | mission_start_command | uint8 | - | 0 또는 1 | 임무 시작 시 | 임무 시작 명령 |

## STM32 -> Unity
S2U -> STM32 to Unity
| ID | 데이터명 | 자료형 | 단위 | 유효 범위 | 전송 시점 | 설명 |
|---|---|---|---|---|---|---|
| S2U-001 | target_altitude | float | m | TBD | 주기적 | 목표 고도|
| S2U-002 | target_heading | float | degree | 0.0 이상 360.0 미만 | 주기적 | 목표 진행방향 |
| S2U-003 | target_speed | float | m/s | TBD | 주기적 | 목표 속도 |
| S2U-004 | waypoint_list| list | - | 별도 명시 | 초기, 변경 시 | 목표 waypoint list | 
| S2U-005 | current_waypoint_index | uint8 | - | 0 ~ TBD-1 | 주기적 | 현재 waypoint 순번 |
| S2U-006 | mission_state | uint8 | - | 0 , 1 , 2 | 주기적 | 임무 단계 |
| S2U-007 | data_status | uint8 | - | 0 , 1 , 2 | 주기적 | 마지막으로 수신한 항공기 데이터의 유효성 |
| S2U-008 | fuel_status | uint8 | - | 0 , 1 , 2 | 주기적 | 연료 상태 |

### waypoint list 세부 
| ID | 데이터명 | 자료형 | 단위 | 유효 범위 | 전송 시점 | 설명 |
|---|---|---|---|---|---|---|
| S2U-009 | waypoint_latitude | float | degree | -90.0 ~ 90.0 | 초기, 변경 시 | 목표 waypoint 위도 |
| S2U-010 | waypoint_longitude | float | degree | -180.0 ~ 180.0 | 초기, 변경 시 | 목표 waypoint 경도 |
| S2U-011 | waypoint_altitude | float | m | TBD | 초기, 변경 시 | 목표 waypoint 고도 |

### Mission State

| 값 | 상태 |
|---:|---|
| 0 | INITIALIZE |
| 1 | NAVIGATE |
| 2 | MISSION_COMPLETE |

### Data Status

| 값 | 상태 | 설명 |
|---:|---|---|
| 0 | UNKNOWN | 항공기 데이터를 아직 수신하지 않음 |
| 1 | VALID | 마지막으로 수신한 데이터가 유효함 |
| 2 | INVALID | 마지막으로 수신한 데이터가 유효하지 않음 |

### Fuel Status

| 값 | 상태 | 설명 |
|---:|---|---|
| 0 | UNKNOWN | 연료 데이터를 아직 수신하지 않음 |
| 1 | NORMAL | 연료량이 정상 범위임 |
| 2 | LOW | 연료량이 부족 기준 이하임 |
