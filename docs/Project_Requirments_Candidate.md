# 1차 기능 요구사항 후보

## ○STM32 
### 데이터/상태 처리 

- 시뮬레이터로부터 항공기 상태 정보를 수신한다.<br>
- 수신한 데이터의 유효성을 검사한다.<br>
- 상태 정보를 기반으로 현재 비행 상태를 판단한다.<br>
- 현재 연료 상태를 판단한다.<br>
- 현재 환경 상태를 판단한다.<br>

### 항법/ Guidance

- 현재 위치와 목표 지점을 기반으로 Guidance를 계산한다.<br>
- Gudiance 결과를 기반으로 목표 Heading을 생성한다.<br>
- Guidance 결과를 기반으로 목표 Altitude를 생성한다.<br>
- Guidance 결과를 기반으로 목표 Speed를 생성한다.<br>
- 현재 Waypoint 도달 여부를 판단한다.<br>
- Waypoint 도달 시 다음 Waypoint로 전환한다.<br>
- 비행경로 이탈 여부를 판단한다.<br>
- 경로 이탈 시 목표 경로로 복귀하기 위한 Guidance를 계산한다.<br>

### 이착륙 / 환경

- 현재 상태를 기반으로 이륙 가능 여부를 판단한다.<br>
- 현재 상태를 기반으로 착륙 가능 여부를 판단한다.<br>
- 풍향과 기체 진행 방향을 이용하여 정풍 / 배풍 상태를 판단한다.<br>
- 착륙 조건이 적절하지 않은 경우 착륙을 수행하지 않도록 판단한다.<br>
- 필요시 선회/Holding 상태로 전환한다.<br>

### 충돌 / 경로 회피 (필수가 아님 추가적인 기능을 넣는다면)

- 비행경로상의 장애물 존재 여부를 판단한다.<br>
- 장애물이 존재할 경우 회피 경로를 생성한다.<br>
- 주변의 항공기의 존재 여부를 판단한다.<br>
- 주변 항공기와의 충돌 위험 여부를 판단한다.<br>
- 충돌 위험이 존재할 경우 회피 Gudiance를 생성한다.<br>

### 비정상/비상

- 연료가 설정된 기준 이하로 감소했는지 판단한다.<br>
- 수신 데이터 이상 여부를 판단한다.<br>
- 비행 지속이 위험한 상태인지 판단한다.<br>
- 비상 상태 발생 시 정상 비행 Guidance보다 비상절차를 우선한다.<br>

## ○시뮬레이터
### 항공기 상태 데이터 생성 및 추출
- Unity상의 기체 위치 데이터를 추출한다.<br>
- 기체의 현재 속도 데이터를 추출한다.<br>
- 실제 항공기 센서를 모사한 가상의 센서 데이터를 생성한다.<br>
  ● 위도 / 경도<br>
  ● 고도<br>
  ● Roll / Pitch / Yaw<br>
  ● 가속도<br>
  ● 기체 속도<br>
  ● 연료 상태<br>

- 풍속 및 풍향 등의 환경 데이터를 생성한다.<br>

### STM32 데이터 송수신 인터페이스 구축

- Unity와 STM32 간 데이터를 실시간으로 송수신할 수 있는 통신 인터페이스를 구축한다.<br>
- 시뮬레이터에서 생성한 항공기 상태 및 환경 데이터를 STM32로 전송한다.<br>
- STM32에서 생성한 Guidance 및 목표 값을 수신한다.<br>
- STM32에서 수신한 명령을 시뮬레이터의 항공기 제어에 반영한다.<br>
- 실제 비행 역학을 고려한 기체 제어<br>
- 항공기의 기본적인 비행 역학을 반영하여 기체의 움직임을 구현한다.<br>
- STM32로부터 전달받은 Target Heading, Target Altitude, Target Speed 등의 목표 값을 기반으로 기체를 제어한다.<br>
- 이륙, 상승, 순항, 하강, 접근 및 착륙 상태에 따른 기체 움직임을 구현한다.<br>
- 풍속 및 풍향과 같은 환경 요소가 기체의 움직임에 영향을 줄 수 있도록 구현한다.<br>

### 실제 좌표계 및 지형 연동

- Unity 상의 가상 좌표계를 실제 지구상의 위도 / 경도 좌표계와 연동한다.<br>
- Unity 좌표와 위도 / 경도 간 변환 기능을 구현한다.<br>
- 대한민국 실제 좌표 데이터를 기반으로 비행 영역을 구성한다.<br>
- 실제 지형 데이터를 활용하여 대한민국 지역의 3D 지형을 시뮬레이터에 구현한다.<br>

### 비행 모습 시각화

- B737 형태의 민항기 모델을 시뮬레이터에 구현한다.<br>
- 지상 활주, 이륙, 상승, 순항, 하강, 접근 및 착륙 과정을 시각적으로 표현한다.<br>
- 항공기의 자세와 이동 상태가 실제 시뮬레이션 데이터와 일치하도록 렌더링한다.<br>
- 비행 모습을 실시간으로 부드럽게 확인할 수 있도록 화면에 출력한다.<br>
- 비행기의 WayPoint와 현재 비행기의 위치를 확인할 수 있는 비행지도를 출력한다.<br>
