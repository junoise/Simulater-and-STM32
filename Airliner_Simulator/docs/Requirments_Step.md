# 구현 범위 분류
<br><br><br>
## 1차구현(필수구현)
  ### STM32
  - STM32 와 Unity간 항공기 상태 및 목표 값을 주기적으로 송수신한다.
  - 수신한 데이터의 유효성 검사
  - 상태 정보 기반 비행 상태 판단
  - 연료 상태 판단
  - 현재 위치와 목표 지점을 기반으로 Guidance계산
  - Guidance 결과 기반 목표 Heading/Altitude/Speed 생성
  - Waypoint 도달 여부 판단 및 목표 전환
  ### Simulater
  - STM32 와 Unity간 항공기 상태 및 목표 값을 주기적으로 송수신한다.
  - Unity 상 기체 위치 데이터 추출
  - 기체 데이터 UI표시
  - 수신한 Heading/Altitude/Speed/Guidance 를 기반으로 자동조종 로직에 반영한다.
  - 자동 조종 로직은 현재 항공기 상태가 수신한 목표값에 점진적으로 수렴하도록 기체를 제어한다.
  - 시작할 시 비행기는 순항 상태로 시작한다.
  - 간단한 조작(keyBoard 방향키)으로 비행기를 조작할 수있도록 기능을 추가한다.
<br><br>
## 2차 구현
  ### STM32
  -  비행기 이/착륙 가능 여부 판단
  -  현재 환경 상태를 기반으로 판단(풍향,풍속,기후 등)
  -  착륙이 안된다고 판단하였을 때 다른 제시
  -  비정상 작동하는 경우(연료 부족 ,데이터 수신 불가 등)를 추가 후 대처
  -  비행 경로 이탈 여부 및 이탈 시 Guidance 생성
  ### Simulater
  -  대한민국 실제 좌표 데이터를 기반으로 비행영역 구성
  -  B737 형태의 민항기 모델을 구현
  -  지상 활주, 이륙, 상승, 하강, 접근 및 착륙 과정을 시각적으로 표현 (순항상태 시작 -> 출발 대기 상태 시작)
  -  인터페이스를 실제 계기판과 유사하게 접근
  -  비행기의 Waypoint와 현재 위치를 확인 할 수 있는 비행 지도를 출력한다.
 <br><br>
## 향후 확장(시간상 가능하다면)
  - 실제 지형 데이터를 활용하여 대한민국 지역의 3D 지형을 시뮬레이터에 구현한다.
  - 실제 비행 역학을 고려한 기체 제어
  - 비행 경로상의 장애물 존재 여부를 판단
  - 버드 스트라이크 등 실제 긴급상황을 넣어 대처할 수 있는 기능
  - 임의의 비행기 가 있다는 데이터를 만들어 최적의 비행로 설정

<br><br>
상세한 설명: 1차에서는 비행기가 순항 상태에서 시작한다. stm32와 통신을 하며 자동으로 비행기가 목표값에 수렴할 수 있도록 자동 로직을
짜고 그것에 맞게 UI가 반응해야한다.
2차에서는 실제 비행기와 같이 이륙부터 착륙까지 단계별로 구현한다.
수동조작은 시험이나 비정상 상황 처리하거나 만들기 위해 구현하는것이다.
최종 목표는 2차구현 까지이다.
